# منصة التخطيط الإنشائي — نسخة محلية غير متصلة (M01–M06)

تطبيق ويب واحد يعمل بالكامل من المتصفح بدون خادم، بدون تثبيت (`npm install`)، وبدون
اتصال إنترنت في وقت التشغيل. يغطي الموديولات **M01 إلى M06** من خارطة الموديولات
(`المشاريع`, `المستندات`, `BOQ`, `WBS`, `الأنشطة`, `الربط وتوزيع الكميات`) بالإضافة
إلى طبقة حوكمة **M00** (سجل تدقيق، سجل قرارات، صندوق مراجعة، تعارضات) التي تعمل عبر
كل موديول.

## التشغيل

افتح الملف `app/index.html` مباشرة في متصفح حديث (Chrome / Edge / Firefox).
لا حاجة لأي خادم أو تثبيت. البيانات تُحفظ محليًا في المتصفح نفسه (`localStorage`).

> ملاحظة: بعض المتصفحات (خصوصًا Chrome في أوضاع خاصة) قد تُقيّد تخزين `localStorage`
> عند الفتح من `file://` مباشرة إذا كانت إعدادات الخصوصية صارمة جدًا. إذا لاحظت أن
> البيانات لا تُحفظ بين الجلسات، شغّل خادمًا محليًا بسيطًا كخطوة بديلة:
> `npx http-server app -p 8080` ثم افتح `http://localhost:8080`.

عند أول فتح، اضغط **"تحميل مشروع تجريبي كامل (M01–M05)"** من قائمة المشاريع الفارغة
لرؤية تدفق كامل: مشروع معتمد ← BOQ معتمد ← WBS معتمد ← أنشطة مولَّدة (منها نشاط واحد
أُرسل لصندوق المراجعة عمدًا لأنه بلا تطابق في القاموس) — هذا اختياري بالكامل ولا يُحمَّل
تلقائيًا (مبدأ "لا بيانات وهمية تُعرض كبيانات مستخدم").

## ما تم تنفيذه فعليًا (وما لم يُنفَّذ)

| الموديول | الحالة | ملاحظات |
|---|---|---|
| M00 حوكمة | ✅ فعلي | سجل تدقيق، سجل قرارات، صندوق مراجعة، تعارضات — تعمل عبر كل موديول، تُعرض في تبويب "الحوكمة والتدقيق" |
| M01 المشاريع | ✅ فعلي | إنشاء/تعديل، احتساب المعطى الثالث (بداية/نهاية/مدة) وفق تقويم العمل الفعلي، اعتماد يقفل الحقول، تعديل بعد الاعتماد ينشئ مراجعة (Rev) بدل الكتابة فوق السابقة |
| M02 المستندات | ⚠️ جزئي، صادق | تسجيل مستندات وإصدارات مع تحقق SHA-256 فعلي (Web Crypto). **لا يوجد استخراج نصوص/AI تلقائي** من PDF/DOCX في هذه النسخة (يتطلب مكتبات لا يمكن تضمينها بلا اعتماديات) — كل إصدار يُعلَّم صراحة `NOT_AUTOMATED` بدل ادّعاء استخراج وهمي |
| M03 BOQ | ⚠️ جزئي، صادق | استيراد **CSV** فعلي مع مطابقة أعمدة وتحقق لكل صف (لا صفوف تُدرَج بصمت بلا وحدة أو بكمية سالبة). **لا يوجد قارئ Excel (.xlsx)** بلا مكتبة خارجية — احفظ الملف كـ CSV UTF-8 أولًا |
| M04 WBS | ✅ فعلي | محرر شجري (إضافة/تعديل/نقل/حذف/إعادة ترتيب)، تعدد نسخ، قفل عند الاعتماد، قالب أولي **حتمي** (ليس AI) مبني على قوائم مباني/طوابق تُدخلها بنفسك |
| M05 الأنشطة | ⚠️ صادق حول طبيعته | توليد **قائم على قواعد** (مطابقة كلمات مفتاحية + وحدة) — **ليس ذكاءً اصطناعيًا**. كل نشاط مولَّد يحمل ثقة متعددة العوامل وسببها؛ البنود بلا تطابق تُرسَل لصندوق المراجعة بدل توليد نشاط ملفَّق |
| M06 الربط والتوزيع | ✅ فعلي | كل نشاط مولَّد من M05 يُسجَّل كربط `BOQMapping` حقيقي (لا رابط ضمني). تسوية إلزامية: الأصلية = الموزَّعة + المتبقي، وإلا **تحذير حرج** يظهر فورًا ويُرسَل لصندوق المراجعة تلقائيًا (ويُحل تلقائيًا عند التزان أو القبول بتبرير). يدعم تقسيم بند BOQ واحد على عدة أنشطة/مواقع WBS |

**غير مُنفَّذ في هذه النسخة** (مراحل لاحقة في خارطة الموديولات، M07 وما بعدها):
محرك المدة/الإنتاجية المتقدم (M07 الجزء المتقدم)، العلاقات المنطقية/CPM (M08، M11)،
الموارد والتكلفة (M09)، DCMA (M12)، تصدير XER (M13).

## قيود متعمدة لهذه النسخة (Offline)

- **لا خادم، لا قاعدة بيانات حقيقية**: كل البيانات JSON واحد داخل `localStorage`
  المتصفح. استخدم **"تصدير نسخة احتياطية"** بانتظام — فقدان بيانات المتصفح
  (مسح الكاش، متصفح آخر، جهاز آخر) يعني فقدان البيانات فعليًا. **الاستيراد
  يستبدل كل البيانات الحالية بالكامل**، وليس دمجًا.
- **لا تخزين فعلي لملفات المستندات**: يُحسب SHA-256 والحجم فقط؛ المحتوى نفسه لا
  يُخزَّن (لا يوجد خادم لحفظه). هذا موثَّق صراحة في واجهة M02 نفسها.
- **"الدور" في الشريط العلوي توجيهي فقط وليس أمانًا حقيقيًا**: لا يوجد خادم
  ليفرضه، فأي شخص يفتح الملف يمكنه تغييره. الأمان الفعلي (RBAC مُطبَّق من خادم)
  يحتاج النسخة المتصلة (server-backed) الموضحة في خارطة الموديولات.
- **مستخدم واحد لكل نسخة متصفح**: لا مزامنة بين أجهزة أو مستخدمين. تعدد
  المستخدمين الحقيقي يحتاج خادمًا مركزيًا (نطاق مستقبلي، وليس هذه النسخة).
- بلا مكتبات خارجية إطلاقًا (لا React، لا CDN، لا npm) — HTML/CSS/JS عادي فقط،
  خطوط النظام الافتراضية، تخزين متصفح أصلي.

## بنية الملفات

```
app/
  index.html            نقطة الدخول — افتحها مباشرة
  css/app.css            تنسيق فاتح/داكن (يتبع إعداد النظام)، RTL
  js/db.js                مخزن البيانات (localStorage) — يعكس نموذج بيانات M00-M06
  js/governance.js        M00: سجل تدقيق / سجل قرارات / صندوق مراجعة / تعارضات
  js/confidence.js        حساب الثقة متعددة العوامل لمحرك التوليد في M05
  js/util.js               مساعدات: HTML escaping، تنسيق تواريخ، قارئ CSV، حساب أيام العمل
  js/seed.js               بيانات تجريبية اختيارية (M01-M06 كاملة، بما فيها تقسيم بند BOQ على نشاطين)
  js/app.js                القشرة + التوجيه (hash router)
  js/views/*.js            شاشة كل موديول (projects / documents / boq / wbs / activities / mapping / governance)
```

## الخطوة التالية المقترحة

الأقرب منطقيًا الآن: **M08 (محرك العلاقات المنطقية)** — بناء علاقات CPM (FS/SS/FF +
Lag موجب) بين الأنشطة المعتمدة مع مراجعة منطقية بصرية وفحص دورات، تمهيدًا لمحرك
CPM الكامل (M11). راجع خارطة الموديولات الكاملة والقرار المعماري الأوسع (نسخة
server-backed لاحقة، مصفوفة توافق XER، تدقيق DCMA) في الوثيقة المنشورة سابقًا لهذا
المشروع.
